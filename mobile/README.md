# দ্বীন ইসলাম (DeenIslam) - Native Mobile Application

একটি সম্পূর্ণ ইসলামিক মোবাইল অ্যাপ্লিকেশন যা **Flutter (Dart)** ফ্রেমওয়ার্ক দিয়ে তৈরি করা হয়েছে। একই কোডবেস থেকে সরাসরি **Android (APK & AAB)** এবং **iOS (IPA)** বিল্ড করা যায়।

---

## 🌟 প্রধান ফিচারসমূহ

1. **বেন্তো গ্রিড ড্যাশবোর্ড (Bento Dashboard):**
   - লাইভ নামাজের ওয়াক্ত কাউন্টডাউন ও সময়সূচি।
   - রমজান ও দৈনন্দিন সেহরি-ইফতার ট্র্যাকার (রিয়েল-টাইম প্রগ্রেস বার)।
   - আল্লাহর ৯৯ নাম মোবাইল ভিউ (১টি ফিচার্ড হিরো কার্ড + ৪টি সুষম টাইলস = ৫টি নাম প্রতি ব্যাচে)।
   - সূরা আল-ফাতিহা অডিও তিলাওয়াত প্লেয়ার।
2. **আল-কুরআনুল কারীম (Al-Quran Module):**
   - ১১৪টি সূরার সম্পূর্ণ তালিকা (মাক্কী/মাদানী ফিল্টার ও সার্চ)।
   - সূরা ও আয়াতভিত্তিক রিডার ভিউ (আরবি ফন্ট সাইজ অ্যাডজাস্টার ও বিসমিল্লাহ হেডার)।
   - প্রমিত বাংলা অনুবাদ, আয়াত কপি ও বুকমার্কিং সুবিধা।
   - ক্বারী মিশারি রাশিদ আল-আফাসীর সুললিত কণ্ঠের ব্যাকগ্রাউন্ড অডিও তিলাওয়াত।
3. **হিসনুল মুসলিম - নিত্যদিনের দোয়া (Hisnul Muslim Dua):**
   - ক্যাটাগরিভিত্তিক দোয়া (সকাল-সন্ধ্যা, নামাজ, ঘুম, দৈনন্দিন, বিপদ-আপদ)।
   - আরবি হরফ, বাংলা উচ্চারণ, অর্থ ও হাদিস রেফারেন্স (বুখারী, মুসলিম, তিরমিযী)।
   - ফেভারিট বুকমার্ক ও এক-ক্লিকে দোয়া কপি করার সুবিধা।
4. **নামাজের পূর্ণাঙ্গ সময়সূচি (Prayer Times):**
   - ঢাকা, চট্টগ্রাম, সিলেট সহ বাংলাদেশের প্রধান জেলাভিত্তিক নামাজের সময়।
   - ফজর, যোহর, আসর, মাগরিব, ইশা এবং ইশরাক ও সেহরি ওয়াক্ত।
5. **আল্লাহর ৯৯টি গুণবাচক নাম (Asmaul Husna):**
   - সম্পূর্ণ ৯৯টি নামের বিশুদ্ধ আরবি ক্যালিগ্রাফি, বাংলা উচ্চারণ, অর্থ ও বিশদ ব্যাখ্যা।
   - লাইভ সার্চ ও ফিল্টারিং সুবিধা।
6. **ডিজিটাল তাসবীহ (Digital Tasbih):**
   - ৩৩, ৯৯, ১০০ ও আনলিমিটেড টার্গেট কাউন্টার।
   - সুবহানাল্লাহ, আলহামদুলিল্লাহ, আল্লাহু আকবার সহ বিভিন্ন জিকির সিলেক্টর।
   - টাচ রেসপন্স ও সার্কুলার প্রগ্রেস অ্যানিমেশন।
7. **কিবলা কম্পাস (Qibla Compass):**
   - বাংলাদেশের অবস্থান থেকে ২৬৮° কোণে কাবার দিক নির্দেশক কম্পাস ডায়াল।
8. **যাকাত ক্যালকুলেটর (Zakat Calculator):**
   - নগদ অর্থ, স্বর্ণ, রৌপ্য ও ব্যবসায়িক পণ্যের ওপর ২.৫% যাকাত গণনাকারী।
9. **ডার্ক ও লাইট মোড (Material 3 Theme):**
   - ওয়েবসাইটের এমারেল্ড (`#059669`) ও অ্যাম্বার (`#D97706`) কালার স্কিমের সাথে নিখুঁত সামঞ্জস্য।

## 🛠️ প্রজেক্ট রান করার নিয়মাবলী

### ১. Flutter ইনস্টল নিশ্চিত করুন:
```bash
flutter --version
```

### ২. ডিপেনডেন্সি ইনস্টল করুন:
```bash
cd mobile
flutter pub get
```

### ৩. অ্যাপ রান করুন (Android Device / Emulator):
```bash
flutter run
```

### ৪. রিলিজ APK বিল্ড করুন:
```bash
flutter build apk --release
```
বিল্ড হওয়া APK ফাইলটি পাওয়া যাবে: `build/app/outputs/flutter-apk/app-release.apk`
