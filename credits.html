কৃতজ্ঞতা স্বীকার

এই প্ল্যাটফর্মটি নির্মাণে ব্যবহৃত সকল মুক্ত ও উন্মুক্ত সোর্স (Open Source) ডেটাবেজ, API এবং সংশ্লিষ্ট গবেষকদের প্রতি আমাদের সশ্রদ্ধ কৃতজ্ঞতা।

উন্মুক্ত দ্বীনি API

কুরআন, হাদিস ও নামাজের নির্ভুল ডেটা সোর্স

  • AlQuran.cloud API

    সম্পূর্ণ কুরআন শরীফের আরবি মূল পাঠ, বাংলা অনুবাদ ও অডিও তিলাওয়াতের জন্য।

  • Hadith API (Fawaz Ahmed)

    সহীহ বুখারী, মুসলিমসহ সিহাহ সিত্তার বিশাল হাদিস ভাণ্ডার ও রাবীর তথ্য।

  • Aladhan.com API

    জিপিএস ভিত্তিক সঠিক নামাজের ওয়াক্ত, সাহরী-ইফতার সময়সূচি ও হিজরি ক্যালেন্ডার।

  • BigDataCloud Reverse Geocoding

    ব্যবহারকারীর ভৌগোলিক অবস্থান নির্ণয়পূর্বক স্থানীয় নামাজের ওয়াক্ত নির্ধারণ।

প্রযুক্তি ও ফন্ট

আধুনিক, নির্ভরযোগ্য ও দ্রুতগতির ওপেন ফ্রেমওয়ার্ক

  • Tailwind CSS

    লাইটওয়েট ইউটিলিটি ক্লাস ও রেসপন্সিভ আর্কিটেকচারাল ডিজাইনের জন্য।

  • Google Fonts (Amiri, Noto Sans Bengali)

    বিশুদ্ধ নাতালিক-শৈলীর আরবি ক্যালিগ্রাফি ও সুস্পষ্ট বাংলা হরফ উপস্থাপনে।

  • Heroicons

    পরিচ্ছন্ন ও মিনিমালিস্টিক ভেক্টর আইকন সেট।

  • HTML5 Web Audio & Geolocation APIs

    তিলাওয়াত অডিও স্ট্রিমিং ও ডিভাইসের সেন্সরভিত্তিক কিবলা কম্পাস পরিচালনায়।

উন্নয়ন ও অবদান
